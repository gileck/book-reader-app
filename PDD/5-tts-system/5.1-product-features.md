# 5.1 TTS Product Features

## Word Highlighting

### Purpose
Visual feedback showing which word is currently being spoken, helping users follow along during audio playback.

### Modes

**Word Mode:**
- Individual word highlighted in yellow
- Highlight moves from word to word as spoken
- Precise synchronization with audio timing
- Best for: Active reading, language learning

**Line Mode:**
- Entire line containing current word highlighted
- Yellow bar spans line width
- Easier to follow with peripheral vision
- Best for: Casual listening, relaxed reading

**Off:**
- No highlighting during playback
- Pure audio experience
- Reduces visual distraction
- Best for: Audiobook-style listening

### Customization
- Toggle between modes in settings
- Custom highlight colors (yellow default)
- Adjustable timing offset (-500ms to +500ms)
- Saved per user preference

> **📘 Technical Deep Dive:** See [Word Highlighting CSS](technical/word-highlighting-css.md) for the performance-optimized implementation details.

## Auto-Play

### Purpose
Continuous listening without manual interaction, automatically advancing through sentences.

### Behavior
1. Current sentence finishes playing
2. System immediately loads next sentence
3. Audio begins playing new sentence (no gap)
4. Visual highlighting updates to new sentence
5. Process continues until user pauses or chapter ends

### User Control
- Play/pause button controls flow
- Skip ahead/back interrupts auto-play
- Manual navigation maintains auto-play state
- Chapter end: Optional prompt to continue

### Skip Logic
- Automatically skips image elements
- Plays all text chunks sequentially
- Handles chapter headers appropriately
- Smooth transitions between content types

> **📘 Technical Deep Dive:** See [Auto-Play Sentences](technical/auto-play-sentences.md) for the complete auto-play implementation with intent tracking and navigation logic.

## Navigation Controls

### Sentence Navigation
- **Previous Sentence**: Skip back to replay previous sentence
- **Next Sentence**: Skip ahead to next sentence
- **Jump to Specific**: Click sentence to navigate to it
- Keyboard shortcuts: Arrow keys

### Chapter Navigation
- **Previous Chapter**: Return to previous chapter start
- **Next Chapter**: Advance to next chapter start
- Chapter selector dialog for direct access
- Maintains playback state across chapters

### Position Tracking
- Current sentence always highlighted
- Progress bar shows chapter completion
- Sentence counter displays position
- Auto-saves reading position

## Preloading

### Purpose
Ensure seamless playback without delays or buffering between sentences.

### User Experience
- Audio starts instantly when clicking next
- No waiting or loading delays
- Smooth continuous playback
- Professional audiobook quality

### Visual Feedback
- Loading spinner on sentences being prepared
- "Next 2 sentences preloaded" indicator
- Instant playback confirmation
- No interruption to reading flow

### Behavior
- Always 2 sentences ahead pre-loaded
- Loads in background during playback
- Prioritizes current sentence first
- Cancels stale requests if user jumps ahead

> **📘 Technical Deep Dive:** See [Preload & Cache Audio](technical/preload-cache-audio.md) for the three-layer caching strategy and rolling window preloading implementation.

## Error Handling

### TTS Service Failures

**Symptoms:**
- Audio fails to generate
- Playback doesn't start
- Missing or corrupted audio

**User Experience:**
1. Error notification appears: "TTS service unavailable"
2. Shows provider name and error code
3. Offers actions:
   - Retry current sentence
   - Skip to next sentence
   - Switch TTS provider
4. Dismiss button to hide error

**Recovery:**
- Automatic retry (3 attempts with backoff)
- Falls back to cached audio if available
- Suggests provider switch if repeated failures
- Maintains reading position throughout

### Network Issues

**Offline Mode:**
- Detects network unavailability
- Shows "Content not available offline" message
- Falls back to cached audio where available
- Option to disable offline mode

**Slow Connection:**
- Extended timeout (30 seconds)
- Loading indicator shows progress
- Option to cancel and skip
- Preloading continues in background

### Rate Limiting

**When Approaching Limits:**
- Warning notification at 75% usage
- Cost display shows current usage
- Suggests reducing voice quality tier
- Option to switch to free-tier provider

**When Limit Exceeded:**
- Error: "Monthly limit reached"
- Displays next reset date
- Suggests alternate provider
- Playback paused until resolution

## TTS Provider Switching

### Available Providers

**Google Cloud TTS:**
- 45+ voices
- Best value for money
- Reliable and fast
- Free tier: 4M chars/month

**Amazon Polly:**
- 26+ voices
- Consistent quality
- Long-form neural voices
- Free tier: 5M chars/month

**ElevenLabs:**
- 10+ ultra-realistic voices
- Premium tier only
- Highest quality available
- Free tier: 10K chars/month

### Switching Process

**User Flow:**
1. User opens TTS settings
2. Selects new provider from dropdown
3. Warning appears: "Cached audio will be cleared"
4. User confirms switch
5. Voice selection dialog opens for new provider
6. User chooses voice and hears preview
7. Clicks "Select Voice"
8. Next playback uses new provider

**Impact:**
- All cached audio cleared (different voice)
- New audio generation required
- Cost structure changes
- Voice characteristics change

> **📘 Technical Deep Dive:** See [Word-Audio Synchronization](technical/word-audio-synchronization.md) for SSML mark generation and provider-specific timepoint extraction.

### Cost Considerations
- Each provider has different pricing
- Free tier limits vary significantly
- Usage tracking shows cost per provider
- Recommendations based on usage patterns

## Voice Selection

### Selection Interface
- Provider dropdown at top
- Filter by:
  - Language (English, Spanish, French, etc.)
  - Gender (Male, Female, Neutral)
  - Voice tier (Standard, Neural, Studio)
- Search by voice name
- Preview button plays sample

### Voice Metadata
Each voice shows:
- Voice name (e.g., "en-US-Neural2-F")
- Language and locale
- Gender
- Tier/Quality level
- Provider

### Preview Feature
- Click preview button
- Hears sample: "This is how I sound reading your book"
- Plays at current speed setting
- Uses current text from reading position
- Multiple previews allowed

### Saving Preference
- Selected voice saved to user profile
- Synced across devices
- Persists across sessions
- Can set different voice per book (future)

## Speed Control

### Range
- Minimum: 0.5x (half speed, very slow)
- Maximum: 2.0x (double speed, very fast)
- Increment: 0.1x for fine control
- Default: 1.0x (natural speaking pace)

### Adjustment
- Slider in speed control dialog
- Real-time preview as you adjust
- Apply button confirms change
- Reset to 1.0x button available

### Use Cases
- **0.5x-0.8x**: Language learning, difficult material
- **0.9x-1.1x**: Comfortable listening, natural pace
- **1.2x-1.5x**: Faster consumption, familiar material
- **1.6x-2.0x**: Speed reading, review, time-constrained

### Persistence
- Speed saved per user
- Applies to all future playback
- Maintains across sessions and devices
- Independent of voice selection
