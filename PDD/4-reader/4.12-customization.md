# 4.12 Customization

## Purpose

The Customization system allows users to personalize their reading experience with extensive options for themes, typography, colors, and reading behavior. All settings are saved per user and synced across devices.

## Design/Layout

**Customization Panel:**
- Slides in from right side of screen
- Organized into collapsible sections
- Real-time preview of changes
- Reset to defaults button at bottom
- Close button (X) or click outside to dismiss

**Sections:**
1. **Theme & Colors**
2. **Typography**
3. **Reading Preferences**
4. **TTS Settings**

## Theme & Colors

**Theme Selection:**
- Light mode / Dark mode toggle
- Warm (sepia), Neutral, Cool color presets
- Custom color picker for advanced users

**Text Colors:**
- Preset colors: Black, Dark Gray, Warm Brown, Custom
- Real-time preview in reading area
- Separate settings for light/dark mode
- Color picker for custom colors

**Highlight Colors:**
- **Word Highlight**: Yellow (default), 12 presets, custom picker
- **Sentence Highlight**: Light blue (light mode), Dark blue (dark mode)
- **Search Highlight**: Bright yellow
- Semi-transparent overlays (40% opacity)

**Background:**
- Warm sepia (Apple Books style)
- White
- Light gray
- Dark mode: Charcoal, True black, Dark gray
- Custom background color option

## Typography

**Font Family:**
- **Serif Options**:
  - Georgia (default)
  - Crimson Text
  - Merriweather
  - Lora
  - Playfair Display
- **Sans-Serif Options**:
  - Inter
  - Roboto
  - Open Sans
  - Lato
  - Source Sans Pro
- **Monospace**:
  - Courier
  - Monaco
  - Consolas
- Live preview with sample text

**Font Size:**
- Slider: 0.8x to 2.0x (0.1x increments)
- Default: 1.0x (16-18px base)
- Real-time update in reading area
- Separate control in fullscreen mode

**Line Height:**
- Slider: 1.0 to 2.5 (0.1 increments)
- Default: 1.6 (comfortable reading)
- Affects paragraph spacing
- Preview updates immediately

**Chunk Spacing:**
- Space between sentences/paragraphs
- Range: 0 to 2.0em
- Default: 0.8em
- Helps visual separation

## Reading Preferences

**Highlight Modes:**
- **Word Mode**: Highlights individual words during TTS
- **Line Mode**: Highlights entire line containing current word
- **Off**: No highlighting during playback
- Toggle enabled/disabled

**Bionic Reading:**
- Toggle on/off
- Bolds first 40-60% of each word
- **Exam**ple: **Read**ing **bec**omes **fast**er
- Works with TTS highlighting

**Auto Font Scaling:**
- Focus mode feature
- Automatically scales long sentences to fit screen
- Toggle enabled/disabled
- Minimum size: 65% of normal

**Auto-Scroll:**
- Fullscreen mode feature
- Speed slider: 20-200 pixels/second
- Default: 60 px/sec
- Smooth continuous scrolling

**Reading Mode Preference:**
- Default mode when opening reader
- Options: Full or Focus
- Saved per user
- Can be overridden by URL parameter

## TTS Settings

**Enable/Disable:**
- Master toggle for TTS functionality
- When disabled, audio controls hidden
- Saves on API costs
- Preserves other TTS settings

**Provider & Voice:**
- Links to voice selection dialog
- Shows current voice: "Google Neural2-F"
- Quick access to change voice

**Playback Speed:**
- 0.5x to 2.0x slider
- Current speed displayed
- Sample playback button

**Word Timing Offset:**
- -500ms to +500ms slider
- Fine-tunes word highlight synchronization
- Compensates for voice-specific delays
- Default: 0ms

## User Interactions

**Opening Customization:**
1. User clicks paintbrush icon (settings)
2. Panel slides in from right (300ms animation)
3. All current settings displayed
4. Sections start expanded or collapsed based on last state

**Changing Theme:**
1. User in light mode with warm theme
2. Toggles to dark mode
3. Background instantly changes to dark charcoal
4. Text color switches to off-white
5. Highlight colors adjust for dark background
6. All changes preview in real-time

**Adjusting Font Size:**
1. User finds text too small
2. Opens typography section
3. Drags font size slider from 1.0x to 1.3x
4. Text in reading area scales up immediately
5. Line spacing adjusts proportionally
6. User reads comfortably

**Selecting Custom Colors:**
1. User wants specific text color
2. Clicks "Custom" in text color section
3. Color picker opens
4. User selects RGB or enters hex code #2c3e50
5. Color applies to reading area in real-time
6. Saved for future sessions

**Enabling Bionic Reading:**
1. User toggles bionic reading on
2. First part of each word immediately becomes bold
3. User tests reading speed
4. Finds it helpful, leaves enabled
5. Works with TTS highlighting

**Resetting to Defaults:**
1. User experimented with many settings
2. Clicks "Reset to Defaults" button
3. Confirmation: "Reset all customization settings?"
4. User confirms
5. All settings revert to defaults
6. Reading area updates immediately

## Settings Persistence

**Saved Settings:**
- All customization preferences saved to database
- Associated with user account
- Sync across devices (desktop, mobile, tablet)
- Persist across sessions
- Survive app updates

**Real-Time Sync:**
- Changes apply immediately in UI
- Saved to database after 1 second (debounced)
- No manual save needed
- Cloud sync for cross-device

**Per-Book Settings:**
- Most settings global (apply to all books)
- Some settings per-book (future):
  - Font size preference
  - TTS voice preference
  - Reading mode preference

## Visual States

**Panel Open:**
- Slides in smoothly from right
- Backdrop darkens slightly
- Reading area shifts left on desktop
- Full overlay on mobile

**Setting Changed:**
- Control highlights briefly
- Preview updates immediately
- Save indicator (cloud icon) pulses
- No interruption to reading

**Applying Changes:**
- Smooth transitions (200ms)
- No flash or flicker
- Gradual color changes
- Font changes don't reflow jarring

**Reset Confirmation:**
- Modal dialog overlay
- Warning icon
- "Are you sure?" message
- Cancel and Confirm buttons

## Responsive Behavior

**Desktop:**
- Panel slides from right (400px width)
- Doesn't cover reading area
- Hover states on all controls
- Full feature set

**Tablet:**
- Similar to desktop
- Slightly narrower panel (350px)
- Touch-optimized sliders
- Bottom sheet alternative

**Mobile:**
- Full-screen overlay
- Stacked layout
- Large touch targets
- Swipe down to dismiss
- Bottom safe area padding

## Use Cases

**Accessibility:**
- Increase font size for vision impairment
- High contrast mode for readability
- Custom colors for dyslexia support
- Line spacing for tracking

**Personal Preference:**
- Favorite fonts for comfort
- Preferred color schemes
- Reading mode optimization
- Speed adjustments for efficiency

**Different Environments:**
- Dark mode for night reading
- Larger text for mobile
- Higher contrast for bright sunlight
- Adjusted speeds for different materials

**Optimization:**
- Fine-tune TTS synchronization
- Perfect font size for device
- Ideal spacing for reading speed
- Customized highlighting for focus
