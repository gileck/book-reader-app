# 4.1 Reading Modes Overview

## Purpose

The Reader offers five specialized modes accessible via a floating tab navigation system. Each mode is optimized for different reading activities, and users can switch between them instantly without losing their place in the book.

## Design/Layout

**Tab Navigation Bar:**
- Floating pill-shaped bar at the top of the reading area
- Semi-transparent dark background with backdrop blur effect
- Five tabs arranged horizontally: **Full** | **Focus** | **QA** | **Search** | **Overview**
- Active tab highlighted with white background
- Inactive tabs shown in light gray text
- Collapsible to minimize distraction (reduces to just active tab name)
- iOS Dynamic Island-inspired aesthetic

**Visual Design:**
- Rounded corners (16px radius)
- Subtle drop shadow for elevation
- Smooth transitions when switching tabs (200ms ease-out)
- Hover states on inactive tabs (slight brightness increase)
- Mobile: Full-width bar at top, tabs scroll horizontally if needed

## The Five Modes

### 1. Full Reading Mode
**Best for:** Traditional reading, consuming multiple paragraphs at once

**Key Features:**
- Continuous scrolling through chapter
- Multiple paragraphs visible simultaneously
- Current sentence highlighted in warm yellow
- Fullscreen mode available
- Auto-scroll during audio playback

### 2. Focus Reading Mode
**Best for:** Distraction-free reading, language learning, attention optimization

**Key Features:**
- Single sentence displayed large and centered
- Previous and next sentences shown dimmed above/below
- Auto font scaling for long sentences
- Bionic reading mode option
- Click anywhere to advance

### 3. Q&A Chat Mode
**Best for:** Understanding difficult material, studying, exploring themes

**Key Features:**
- AI-powered chat about book content
- Ask questions with full chapter context
- Conversation history preserved
- Multiple AI models available
- Quick prompts for common questions

### 4. Search Mode
**Best for:** Finding specific passages, references, or topics

**Key Features:**
- Search current chapter or entire book
- Real-time results as you type
- Results grouped by chapter
- Highlight search terms in context
- Navigate directly to results

### 5. Overview Mode
**Best for:** Chapter summaries, study aids, quick review

**Key Features:**
- AI-generated chapter summaries
- Multiple format options (bullets, paragraphs, Q&A)
- Adjustable length and complexity level
- Save multiple overviews per chapter
- Export or regenerate

## User Interactions

**Switching Modes:**
1. User clicks different tab in navigation bar
2. Current mode content fades out (150ms)
3. New mode content fades in (150ms)
4. Reading position preserved across all modes
5. URL updates to reflect current mode
6. User's mode preference saved

**Collapsing Navigation:**
1. User clicks collapse icon (chevron)
2. Bar shrinks to show only active tab name
3. Click again to expand full navigation
4. State persists during session

**Keyboard Shortcuts (Future):**
- `1` - Full mode
- `2` - Focus mode
- `3` - Q&A mode
- `4` - Search mode
- `5` - Overview mode
- `Tab` - Cycle through modes

**Reading Position Sync:**
- All modes share the same reading position (sentence index)
- Switching from Full to Focus shows same sentence
- Search results navigate to specific sentence
- Bookmark creation works from any mode
- Audio playback continues across mode switches

**Mobile Behavior:**
- Tab bar sticky at top during scroll
- Swipe gestures to switch modes (optional)
- Bottom sheet navigation (alternative design)
- Large touch targets (minimum 44x44px)

## Mode Selection Guidance

**For New Users:**
- Default starts in Full mode (most familiar)
- First-time tooltip suggests trying Focus mode
- Mode descriptions shown on hover

**Recommended Modes by Use Case:**
- **Casual Reading**: Full mode
- **Language Learning**: Focus mode with TTS
- **Studying**: Q&A mode + Overview mode
- **Research**: Search mode
- **Skimming**: Overview mode
- **Audiobook-style**: Full or Focus with audio

## Visual States

**Tab States:**
- **Active**: White background, dark text, bold font
- **Inactive**: Transparent background, light gray text
- **Hover**: Slight brightness increase, cursor pointer
- **Disabled**: Grayed out (if mode unavailable for current content)

**Loading States:**
- Tab shows loading spinner when mode initializing
- Content area shows skeleton loader
- Mode becomes active after content ready

**Error States:**
- If mode fails to load, shows error message
- "Retry" button to attempt reload
- Option to switch to different mode
