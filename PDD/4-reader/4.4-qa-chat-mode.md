# 4.4 Q&A Chat Mode

## Purpose

Q&A Chat Mode provides an AI-powered conversation interface where users can ask questions about book content, request explanations, and explore themes. The AI has full context of the current chapter and can reference the user's reading position.

## Design/Layout

**Chat Interface:**
- Clean chat layout (800px max width, centered)
- Message bubbles:
  - User messages: Right-aligned, blue background
  - AI responses: Left-aligned, gray background
  - Timestamps shown on hover
- Scrollable conversation history
- Input area fixed at bottom

**Input Area:**
- Multiline text input with auto-resize (1-5 lines)
- "Send" button (always visible, disabled when empty)
- Context indicator showing current settings
- Model selector dropdown
- Settings gear icon for configuration
- Collapsible to maximize chat viewing area

**Settings Panel:**
- Slides in from right side
- **AI Model Selection**: Dropdown with GPT, Claude, Gemini options
- **Answer Customization**:
  - Length: Brief, Short, Medium, Detailed
  - Level: Simple, Intermediate, Advanced
  - Style: Casual, Professional, Tutoring, Analytical
- **Quick Prompts**: Saved question templates
- **Cost Management**: Estimation toggle, approval threshold
- Close button returns to chat

**Quick Prompts Button:**
- Lightning bolt icon in input area
- Shows when input is empty
- Opens popup with saved prompts
- Click prompt to insert into input

## User Interactions

**Asking Questions:**
1. User types question in input box
2. Input auto-resizes as text grows
3. Context indicator shows "Using last 10 sentences"
4. User presses Enter or clicks Send
5. User message appears in chat
6. AI "thinking" indicator displays
7. AI response streams in word-by-word
8. Cost displayed below AI message

**Using Quick Prompts:**
1. User clicks lightning bolt icon
2. Popup shows saved prompts:
   - "Summarize this chapter"
   - "Explain this concept in simple terms"
   - "What are the key themes?"
3. User clicks a prompt
4. Prompt populates input box
5. User can edit before sending or send immediately

**Replying to Messages:**
1. User hovers over previous AI message
2. "Reply" button appears
3. Click reply
4. Input box shows "Replying to: [message preview]"
5. New question references that specific message
6. Creates threaded conversation

**Adjusting Context:**
1. User clicks context dropdown
2. Options: 1, 5, 10, 20, 50, or ALL sentences
3. Selection updates immediately
4. Next question uses new context amount
5. Indicator updates: "Using last 50 sentences"

**Cost Estimation:**
1. User types question
2. Small text shows estimated cost: "~$0.02"
3. If over approval threshold, confirmation dialog appears
4. User can proceed or cancel
5. Actual cost shown after response received

**Managing Conversation:**
1. **Clear History**: Button at top clears all messages
2. **Export to ChatGPT**: Opens ChatGPT with full context
3. **Scroll to Top/Bottom**: Quick navigation buttons
4. **Copy Message**: Click to copy AI response text

## Special Features

**Context Building:**
- Automatically includes:
  - Book title and author
  - Current chapter number and title
  - Current sentence being read
  - Previous N sentences (user-configurable)
- Shows context preview in settings panel

## Context Configuration - Technical Details

### Context Sentence Options

**Available Options:**
```
Context Sentence Counts:
- 1 sentence   (minimal context)
- 5 sentences  (brief context)
- 10 sentences (default, recommended)
- 20 sentences (extended context)
- 50 sentences (comprehensive context)
- ALL sentences (entire chapter)
```

**Selection Storage:**
```
UserSettings {
  qaContextSentenceCount: number // Default: 10
}
```

**UI Component:**
- Dropdown selector in settings panel
- Radio buttons for clarity
- Visual preview showing actual sentence count
- Character count estimate per option

### Context Assembly Algorithm

**Context Building Process:**
```
Algorithm:
1. Get current reading position: {chapterNumber, chunkIndex}
2. Fetch current chapter content
3. Convert chunks to sentences (runtime split)
4. Determine context range:
   - If contextCount = "ALL": Include all chapter sentences
   - Else:
     a. currentSentenceIndex = derive from chunkIndex
     b. startIndex = max(0, currentSentenceIndex - contextCount)
     c. endIndex = currentSentenceIndex + 1 (includes current)
     d. Extract sentences[startIndex:endIndex]
5. Build context string
6. Add metadata (book, chapter, position)
7. Construct full prompt
```

**Example Context (10 sentences):**
```
Book: "The Great Gatsby" by F. Scott Fitzgerald
Chapter: 3 - "The Party"
Current Position: Sentence 45 of 120

Context (Last 10 sentences):
[Sentence 36] "The lights grow brighter as the earth lurches..."
[Sentence 37] "The orchestra is playing yellow cocktail music..."
...
[Sentence 45] "I believe that on the first night I went to Gatsby's house..."

User Question: "Why is the party described with colors?"
```

**Additional Context Provided:**
```
Metadata sent to AI:
- bookTitle: string
- bookAuthor: string
```

## Prompt Construction - Technical Details

### System Prompt

**Base System Prompt:**
```
You are a helpful reading assistant for an e-book reader application.
The user is currently reading:

Book: {bookTitle} by {bookAuthor}
Chapter: {chapterNumber} - {chapterTitle}
Position: Sentence {currentPosition} of {totalSentences}

Context from the book:
{contextSentences}

Answer the user's questions about the content clearly and helpfully.
Respond in {answerStyle} style, at {answerLevel} level, with {answerLength} length.
```

**Dynamic Fields:**
- `{bookTitle}`, `{bookAuthor}`: From book metadata
- `{chapterNumber}`, `{chapterTitle}`: From current chapter
- `{currentPosition}`, `{totalSentences}`: Position tracking
- `{contextSentences}`: Assembled context string
- `{answerStyle}`, `{answerLevel}`, `{answerLength}`: User customization

### Answer Length Prompts

**Length Modifiers:**
```
Brief (1-2 sentences):
  "Respond with a brief 1-2 sentence answer. Be concise and direct."

Short (1 paragraph):
  "Respond in a short paragraph (3-5 sentences). Be clear and focused."

Medium (2-3 paragraphs):
  "Provide a medium-length answer of 2-3 paragraphs. Include examples."

Detailed (comprehensive):
  "Provide a detailed, comprehensive answer. Explore the topic thoroughly with examples and analysis."
```

**Implementation:**
```
function getLengthInstruction(length) {
  switch (length) {
    case 'brief':
      return 'Respond in 1-2 sentences maximum. Be extremely concise.';
    case 'short':
      return 'Respond in one paragraph (3-5 sentences). Be focused.';
    case 'medium':
      return 'Provide 2-3 paragraphs. Include relevant examples.';
    case 'detailed':
      return 'Provide a comprehensive answer with thorough analysis.';
  }
}
```

### Answer Level Prompts

**Level Modifiers:**
```
Simple:
  "Explain as if to someone unfamiliar with the topic. Avoid jargon and use simple language."

Intermediate:
  "Provide a balanced explanation suitable for someone with basic knowledge of the subject."

Advanced:
  "Provide an in-depth explanation. Use technical terms where appropriate. Assume reader familiarity with the subject."
```

**Token Estimation Impact:**
```
Level          Avg Tokens Output    Cost Multiplier
----------------------------------------------------
Simple         50-150 tokens        1.0x
Intermediate   100-300 tokens       1.5x
Advanced       200-500 tokens       2.5x
```

### Answer Style Prompts

**Style Modifiers:**
```
Casual:
  "Use a friendly, conversational tone. Be approachable and engaging."

Professional:
  "Use a formal, structured tone. Be clear and authoritative."

Tutoring:
  "Act as a tutor. Guide the learner with questions and gentle explanations. Encourage thinking."

Analytical:
  "Provide critical analysis. Explore multiple perspectives. Question assumptions."
```

**Example Style Differences:**

**Question:** "Why does Gatsby throw lavish parties?"

**Casual Style:**
```
"Gatsby throws these huge parties hoping Daisy will show up! He's basically trying to get her attention by living next door and making his place the hottest spot in town. Pretty romantic, but also kinda sad if you think about it."
```

**Professional Style:**
```
"Gatsby hosts extravagant parties as a strategic means to attract Daisy Buchanan's attention. His mansion is positioned across the bay from hers, and he hopes that the grandeur and publicity of his gatherings will eventually draw her to his home."
```

**Tutoring Style:**
```
"Let's think about Gatsby's motivation. What do we know about his relationship with Daisy? And where does he live in relation to her? Can you see a connection between the parties and his desire to reconnect with her?"
```

**Analytical Style:**
```
"Gatsby's parties serve multiple functions: they're a spectacle designed to capture Daisy's attention, a demonstration of his newfound wealth and status, and a mask for his loneliness. However, one might question whether this approach reveals a deeper misunderstanding of Daisy's values and the fundamental barriers between them."
```

### Combining Customizations

**Full Prompt Example:**
```
System: You are a helpful reading assistant for an e-book reader application.
The user is currently reading:

Book: "The Great Gatsby" by F. Scott Fitzgerald
Chapter: 3 - "The Party"
Position: Sentence 45 of 120

Context from the book:
[Previous 10 sentences...]

Answer the user's questions about the content clearly and helpfully.
Respond in Casual style, at Simple level, with Brief length.

Translation of customizations:
- Use a friendly, conversational tone. Be approachable and engaging.
- Explain as if to someone unfamiliar with the topic. Avoid jargon and use simple language.
- Respond in 1-2 sentences maximum. Be extremely concise.

User: Why does Gatsby throw parties?

AI: Gatsby throws huge parties hoping Daisy will notice and come visit!
```

## Cost Estimation - Technical Details

### Estimation Formula

**Token Calculation:**
```
Estimated Tokens = Context Tokens + Question Tokens + Expected Response Tokens

Where:
- Context Tokens ≈ contextSentences.length × 4 (chars to tokens ratio)
- Question Tokens ≈ userQuestion.length / 4
- Expected Response Tokens = Based on answerLength setting:
  - Brief: 50 tokens
  - Short: 150 tokens
  - Medium: 300 tokens
  - Detailed: 500 tokens
```

**Cost Calculation:**
```
Model Pricing (example, as of 2024):
- GPT-4: $0.03 per 1K input tokens, $0.06 per 1K output tokens
- Claude: $0.015 per 1K input tokens, $0.075 per 1K output tokens
- Gemini: $0.0001 per 1K input tokens, $0.0003 per 1K output tokens

Estimated Cost = (Input Tokens / 1000 × Input Price) + (Output Tokens / 1000 × Output Price)
```

**Example:**
```
Context: 2,000 characters (500 tokens)
Question: "Summarize this chapter" (20 tokens)
Expected response: Medium length (300 tokens)

Using GPT-4:
Input cost: 520 tokens / 1000 × $0.03 = $0.0156
Output cost: 300 tokens / 1000 × $0.06 = $0.018
Total estimated cost: $0.0336 ≈ $0.03
```

## Visual States

**Thinking State:**
- AI message bubble with animated dots
- "Thinking..." text
- Duration depends on response complexity

**Streaming Response:**
- Words appear one-by-one as AI generates
- Smooth animation creates natural feel
- User can start reading before completion

**Error States:**
- **API Error**: Red message bubble with error details
- **Rate Limit**: Warning message with retry countdown
- **No Context**: Prompt to navigate to chapter first
- Retry button available for failed requests

**Empty State:**
- Centered message: "Ask me anything about this chapter"
- Example questions shown:
  - "What is the main theme?"
  - "Summarize in 3 bullet points"
  - "Explain the conflict in this chapter"

**Cost Warnings:**
- Yellow indicator if question expensive (>$0.10)
- Red warning if extremely expensive (>$1.00)
- Approval dialog before sending costly questions
