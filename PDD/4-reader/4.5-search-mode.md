# 4.5 Search Mode

## Purpose

Search Mode enables users to find specific text within the current chapter or across the entire book. Results appear in real-time with highlighted search terms and chapter grouping for easy navigation.

## Design/Layout

**Search Input:**
- Large search box at top with search icon
- Placeholder: "Search in current chapter..."
- Clear button (X) appears when text entered
- Scope toggle below input: "Current Chapter" | "All Chapters"
- Results count displayed: "45 results in 12 chapters"

**Results Area:**
- Scrollable list of results grouped by chapter
- Each chapter section:
  - Chapter header (collapsible)
  - Result count chip (e.g., "8 results")
  - Expand/collapse arrow
- Individual results show:
  - Highlighted search term in context (150 chars)
  - Sentence number within chapter
  - "Go to" button opens result popup

**Result Popup:**
- Modal showing full context (500 chars around match)
- Search term highlighted in yellow
- Action buttons:
  - "Navigate to Result"
  - "Bookmark This"
  - "Close"

**Search History:**
- Recent searches shown when input empty
- Click to re-run previous search
- Clear history option

## User Interactions

**Basic Search:**
1. User types search query
2. Results appear in real-time (300ms debounce)
3. Matching text highlighted
4. Results grouped by chapter
5. Click any result to view popup

**Scope Switching:**
1. User toggles "All Chapters"
2. Progress indicator shows "Searching 24 chapters..."
3. Results expand to include all chapters
4. Chapter groups expand/collapse independently

**Navigating to Result:**
1. User clicks result
2. Popup appears with full context
3. User clicks "Navigate to Result"
4. Reader switches to Full mode (or stays in current)
5. Scrolls to exact sentence
6. Sentence highlighted in yellow
7. Search term within sentence highlighted brighter

**Chapter Grouping:**
1. Results automatically grouped by chapter
2. Chapters with no results hidden
3. Chapter headers show result count
4. Click header to expand/collapse chapter section
5. All chapters start collapsed (except first with results)

**Bookmarking from Search:**
1. User finds interesting result
2. Opens result popup
3. Clicks "Bookmark This"
4. Bookmark created at that position
5. Confirmation toast appears

**Using Search History:**
1. Search input empty
2. History panel shows recent searches
3. Each entry shows:
   - Search query
   - Result count
   - Timestamp (relative, e.g., "2 hours ago")
4. Click to re-run search
5. Clear individual or all history

## Special Features

**Real-Time Search:**
- Debounced typing (300ms delay)
- Shows loading indicator during search
- Cancels previous search if new query entered
- Results update smoothly without jank

**Cache Management:**
- Search results cached for quick re-access
- Cache indicator (disk icon) on cached searches
- Refresh button to re-run search
- Cache cleared when chapter content changes

**Highlighting:**
- **In Results**: Search term in bold yellow background
- **In Context**: Lighter yellow for surrounding text
- **On Navigation**: Bright yellow highlighting when jumping to result
- **Case Insensitive**: Matches regardless of capitalization

**Multi-Chapter Search:**
- Progress bar shows search progress
- "Searching chapter 5 of 24..."
- Can cancel mid-search
- Results stream in as chapters searched

## Visual States

**Empty State:**
- Message: "Enter a search query to find text"
- Search history displayed (if available)
- Example searches suggested:
  - Character names
  - Key themes
  - Important terms

**Searching State:**
- Input shows spinner icon
- Progress bar for multi-chapter search
- Results area shows "Searching..." skeleton

**Results State:**
- Grouped results with expand/collapse
- Highlight search terms
- Hover states on result items
- Clear visual hierarchy

**No Results:**
- Message: "No results found for '[query]'"
- Suggestions:
  - "Try different keywords"
  - "Check spelling"
  - "Expand to all chapters"

**Cached Results:**
- Small disk icon next to result count
- Timestamp: "Results from 5 minutes ago"
- Refresh button to update

## Responsive Behavior

**Desktop:**
- Full-width search input
- Side-by-side layout possible
- All chapters visible in list

**Tablet:**
- Slightly narrower search area
- Chapter sections scroll naturally
- Touch targets enlarged

**Mobile:**
- Full-width search input
- Compact result display
- Bottom sheet for result popup
- Swipe to dismiss popup

## Use Cases

**Finding Passages:**
- Locate specific quotes
- Find character mentions
- Search for themes or motifs
- Reference back to earlier content

**Research:**
- Collect all mentions of a topic
- Find related discussions
- Verify information
- Build citation list

**Study:**
- Find key terms for review
- Locate examples
- Cross-reference concepts
- Create study guides
