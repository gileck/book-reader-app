# 4.11 Navigation & Progress

## Purpose

The navigation and progress system tracks reading position, enables movement through content, and provides visual feedback on reading advancement. It ensures users never lose their place and can easily resume reading.

## Progress Tracking

**What's Tracked:**
- Current sentence index within chapter
- Current chapter number
- Reading session duration
- Total reading time (cumulative)
- Completion percentage (chapter and book)
- Last read timestamp
- Reading mode preference

**Where Progress Shows:**
- Audio controls progress bar (chapter completion)
- Book Library card (overall book progress)
- Reading History page (session details)
- Chapter completion badge (e.g., "Chapter 5 of 24")

**Auto-Save:**
- Progress saved every 30 seconds
- Saved on sentence change
- Saved when closing reader
- Saved on mode switch
- Saved before navigation
- Cloud synced across devices

## Progress Calculation - Technical Details

### Position Storage

**Database Structure:**
```
ReadingProgress {
  userId: ObjectId,
  bookId: ObjectId,
  currentChapter: number,     // 0-based chapter index
  currentChunk: number,        // 0-based chunk index within chapter
  lastReadAt: Date,
  totalReadingTime: number     // Milliseconds
}
```

**Key Points:**
- Position stored as `{currentChapter, currentChunk}` pair
- Chunk = basic unit of navigation (text, header, or image)
- NOT stored as sentence index (sentences computed at runtime)
- NOT stored as character position (too granular)

### Progress Percentage Formula

**Book-Level Progress:**
```
Formula: (totalWordsRead / totalWordsInBook) × 100

Where:
- totalWordsRead = Sum of word counts for all chunks up to current position
- totalWordsInBook = Sum of word counts for all chunks in all chapters
- Result rounded to 2 decimal places
```

**Chapter-Level Progress:**
```
Formula: (wordsReadInChapter / totalWordsInChapter) × 100

Where:
- wordsReadInChapter = Sum of word counts from chunk 0 to currentChunk
- totalWordsInChapter = Sum of all chunk word counts in chapter
```

### Word Count Calculation

**Per Chunk:**
- Each chunk has `wordCount` field stored in database
- Calculated during book upload/parsing
- Formula: `text.split(/\s+/).filter(w => w.length > 0).length`
- Images and headers have `wordCount: 0`

**Aggregation:**
```
Algorithm:
1. Fetch all chapters for book
2. For each chapter up to currentChapter:
   - If chapter < currentChapter: Add all chunk word counts
   - If chapter === currentChapter: Add word counts from chunks 0 to currentChunk
3. Sum all word counts
4. Divide by total book word count
5. Multiply by 100
```

### Update Frequency

**Real-Time Updates:**
- Progress calculated on every chunk change
- UI updated immediately (no debouncing for display)
- Database saves debounced to every 2 seconds
- Prevents excessive database writes during rapid navigation

**Save Triggers:**
```
Immediate Save:
- Reader closed/unmounted
- Chapter changed
- Mode switched
- Book closed

Debounced Save (2 seconds):
- Chunk index changed (sentence navigation)
- Scrolling in Full mode
- Audio playback advancing
```

### Edge Cases

**Beginning of Book:**
- currentChapter: 0, currentChunk: 0
- Progress: 0%
- First chunk word count NOT included (progress starts at 0)

**End of Book:**
- currentChapter: lastChapterIndex
- currentChunk: lastChunkIndex
- Progress: 100% (exactly)
- Completion flag set in database

**Empty Chapters:**
- Chapters with 0 words still counted
- Progress jumps when entering/exiting empty chapter
- Prevents division by zero (handled with 0-checks)

**Images/Headers:**
- Do not contribute to word count
- DO contribute to chunk position
- Progress updates when passing images (position changes, word count doesn't)

**Multi-Device Conflict:**
- Most recent `lastReadAt` timestamp wins
- Position with newer timestamp overwrites older
- No merge logic (last write wins)

### Time Remaining Estimation

**Algorithm:**
```
1. Calculate words remaining: totalWordsInBook - totalWordsRead
2. Determine reading speed:
   - If TTS active: Use audio speed (words per minute from voice)
   - If reading manually: Use historical average (from reading logs)
3. Estimate time: wordsRemaining / wordsPerMinute
4. Format: "X min remaining" or "X hours Y min remaining"
```

**Default Speed:**
- Manual reading: 250 words per minute (average adult)
- TTS playback: Varies by voice and speed setting (150-300 WPM)
- User-specific: Calculated from last 10 reading sessions

### Progress Persistence

**Local Storage (Offline):**
- Position cached in IndexedDB
- Syncs to server when connection restored
- Timeout: 30 seconds retry on network failure

**Server Storage (MongoDB):**
- Single document per user per book
- Indexed on `{userId, bookId}` for fast lookup
- Updated via PATCH API endpoint
- Webhook triggers on update (for cross-device sync)

**Cross-Device Sync:**
- Real-time via WebSocket (when both devices active)
- Polling fallback every 30 seconds
- Conflict resolution: Most recent timestamp wins

## Navigation Methods

**Sentence-Level Navigation:**
- Previous/Next buttons in audio controls
- Click sentence in Full mode to jump to it
- Arrow keys in Focus mode
- Bookmark navigation to exact sentence

**Chapter Navigation:**
- Chapter selector dialog (shows all chapters)
- Previous/Next chapter buttons in header
- Chapter list in audio controls
- Direct chapter links (internal book links)
- URL with chapter parameter

**Quick Navigation:**
- "Jump to Current" (when scrolled away in Full mode)
- "Go to Top" (first sentence of chapter)
- "Resume Reading" from library (last saved position)
- Bookmark jumps (saved positions)
- Search result navigation (specific sentences)

## User Interactions

**Resuming Reading:**
1. User opens book from library
2. Library shows last position: "Chapter 5, 45% complete"
3. User clicks "Continue Reading"
4. Reader opens directly at last sentence read
5. Sentence highlighted briefly to indicate position
6. User can continue immediately

**Switching Chapters:**
1. User clicks chapter selector button
2. Modal shows all 24 chapters with titles
3. Current chapter (5) highlighted
4. User clicks "Chapter 12: The Revelation"
5. Confirmation if mid-chapter: "Save progress and switch?"
6. Reader loads Chapter 12 at first sentence
7. Progress saved for Chapter 5

**Tracking Session:**
1. User starts reading session
2. Timer begins tracking duration
3. Sentence count increments as user reads
4. Every 30 seconds: Progress saved to database
5. User reads for 45 minutes
6. Closes reader
7. Session recorded: "45 min, 234 sentences, Chapter 5"

**Viewing Progress:**
1. In audio controls: Progress bar shows 45% chapter complete
2. Time estimate: "12 min remaining in chapter"
3. Sentence counter: "Sentence 108 of 240"
4. In library: Overall book progress 23% (5 of 24 chapters)

## Visual Indicators

**Progress Bar:**
- Thin bar in audio controls (chapter progress)
- Filled portion in accent color
- Empty portion in light gray
- Percentage on hover: "45%"
- Animates smoothly as user reads

**Chapter Indicator:**
- Text display: "Chapter 5 of 24"
- Percentage: "23% complete"
- Chapter title shown in header
- Updated immediately on chapter change

**Sentence Counter:**
- "Sentence 108 of 240"
- Updates in real-time during reading
- Visible in audio controls
- Helps gauge chapter length

**Time Estimate:**
- "12 min remaining"
- Calculated based on:
  - Remaining sentences
  - Current reading/listening speed
  - Historical pace
- Updates as user progresses

## Chapter Selector Dialog

**Layout:**
- Modal overlay (centered)
- Scrollable list of all chapters
- Each item shows:
  - Chapter number
  - Chapter title
  - Completion badge (if completed)
  - Current indicator (if active)
- Search/filter option for long books
- Close button (X) or click outside to dismiss

**Interaction:**
1. User clicks chapter button or title
2. Dialog opens with chapter list
3. Current chapter highlighted in accent color
4. Completed chapters show green checkmark
5. User clicks desired chapter
6. Dialog closes
7. Reader navigates to selected chapter

## Position Sync

**Cross-Device:**
- Position synced to cloud (MongoDB)
- Read on desktop, continue on mobile
- Automatic conflict resolution (most recent wins)
- Progress updates on app launch
- Real-time sync during active reading

**Cross-Mode:**
- Same position across all 5 reading modes
- Switch from Full to Focus: Same sentence
- Search result navigation: Updates position
- Bookmark navigation: Updates position
- Mode preference saved separately

**Cross-Session:**
- Position persists between sessions
- No manual save needed
- Automatic recovery if app crashes
- Historical positions available (reading history)

## Special Features

**Reading Streaks:**
- Track consecutive days reading
- Badge display in profile (future)
- Streak breaks if miss 24 hours
- Motivational feature

**Chapter Completion:**
- Automatic detection when reaching last sentence
- Completion toast: "Chapter 5 complete!"
- Option to continue to next chapter
- Progress badge in library
- Checkmark in chapter selector

**Smart Resume:**
- Remembers last reading mode used
- Resumes at exact sentence
- Scroll position preserved in Full mode
- Audio state preserved (playing/paused)
- Settings maintained
