# 4.7 Text-to-Speech System

## Purpose

The TTS system provides professional voice narration synchronized with visual text highlighting. Users can choose from 100+ voices across three premium providers and customize playback to their preferences.

## Providers & Voices

**Three Premium Providers:**
1. **Google Cloud TTS**
   - 45+ voices in multiple languages
   - Tiers: Standard, WaveNet, Neural2, Studio, Chirp3-HD
   - Best for: Natural-sounding everyday reading

2. **Amazon Polly**
   - 26+ voices in multiple languages
   - Tiers: Standard, Neural, Long-form, Generative
   - Best for: Consistent quality, reliability

3. **ElevenLabs**
   - 10+ ultra-realistic AI voices
   - Premium tier only
   - Best for: Maximum natural quality, emotional range

**Voice Selection Interface:**
- Provider dropdown at top
- Filter by language and gender
- Search by voice name
- Preview button plays sample with selected voice
- Voice metadata shown: language, gender, tier
- Favorite voices marked with star

## Playback Features

**Speed Control:**
- Range: 0.5x (slow) to 2.0x (fast)
- Fine-tuning in 0.1x increments
- Real-time speed adjustment
- Default: 1.0x (natural speed)
- Preference saved per user

**Word Highlighting:**
- Three modes:
  - **Word Mode**: Individual word highlighted as spoken
  - **Line Mode**: Entire line highlighted
  - **Off**: No highlighting during playback
- Yellow background (customizable color)
- Smooth transitions between words
- Perfect synchronization with audio

> **📘 For Details:** See [TTS System Section 5](../5-tts-system/) for comprehensive documentation. Technical implementation in [Word Highlighting CSS](../5-tts-system/technical/word-highlighting-css.md) and [Word-Audio Synchronization](../5-tts-system/technical/word-audio-synchronization.md).

**Auto-Play:**
- Automatically advances to next sentence when current ends
- Seamlessly continues through chapter
- Skips images automatically
- Optional: Auto-advance to next chapter at chapter end

> **📘 Technical Implementation:** See [Auto-Play Sentences](../5-tts-system/technical/auto-play-sentences.md) for the complete auto-play logic with intent tracking.

**Preloading:**
- Next 2 sentences always pre-loaded
- Audio starts instantly when clicking next
- No delay or buffering
- Loading indicator on sentences being prepared

> **📘 Technical Implementation:** See [Preload & Cache Audio](../5-tts-system/technical/preload-cache-audio.md) for the multi-layer caching strategy.

## User Interactions

**Selecting Voice:**
1. User opens voice selection dialog
2. Selects provider: "ElevenLabs"
3. Filters by gender: "Female"
4. Browses available voices
5. Clicks preview button on "Rachel"
6. Hears sample: "This is how I sound"
7. Clicks "Select Voice"
8. Voice saved, dialog closes
9. Next playback uses new voice

**Adjusting Speed:**
1. User clicks speed button (shows "1.0x")
2. Speed control modal opens
3. Slider currently at 1.0x
4. User drags to 1.3x
5. Sample audio plays at new speed
6. User clicks "Apply"
7. Speed saved, future playback at 1.3x

**During Playback:**
1. User clicks play button
2. Audio starts immediately (pre-loaded)
3. Current word highlights in yellow
4. Word highlight moves in sync with audio
5. When sentence ends, auto-advances to next
6. Next sentence audio starts instantly (pre-loaded)
7. Process continues until user pauses or reaches chapter end

**Switching Providers:**
1. User currently using Google TTS
2. Opens settings, selects "Amazon Polly"
3. Warning: "Cached audio will be cleared"
4. User confirms switch
5. Selects new Polly voice
6. Next playback generates new audio with Polly
7. Audio cached for future use

## Special Features

**Word Timing Offset:**
- Adjustable offset: -500ms to +500ms
- Compensates for voice-specific timing variations
- Fine-tunes highlight synchronization
- Example: Neural voices may need +100ms offset

**Error Handling:**
- TTS service failure: Shows error notification with retry option
- Network issues: Falls back to cached audio if available
- Rate limiting: Warning when approaching API limits
- Provider switch suggested if errors persist

**Cost Management:**
- Each provider has different costs
- Free tiers available (Google: 4M chars/month, Polly: 5M/month)
- Usage tracked in real-time
- Cost warnings when exceeding free tier

**Caching:**
- Audio cached locally for instant replay
- Cache shared across sessions
- Changing voice/speed invalidates cache
- Manual cache clear option in settings

## Visual Feedback

**Playback States:**
- **Playing**: Play button becomes pause icon, word highlighting active
- **Paused**: Pause button becomes play icon, highlighting stops at current word
- **Loading**: Spinner on current sentence being generated
- **Error**: Red error icon with message

**Highlighting Behavior:**
- Current word: Bright yellow background
- Previous words: Return to normal
- Smooth transitions (no flicker)
- Highlight follows audio precisely

**Provider Indicators:**
- Badge showing current provider (e.g., "Google TTS")
- Voice tier indicator (e.g., "Neural2")
- Cost-per-sentence estimate shown

## Responsive Behavior

**Desktop:**
- Voice selection in modal dialog
- Speed control in popup
- Full controls visible

**Mobile:**
- Voice selection in bottom sheet
- Speed as full-screen overlay
- Large touch targets for play/pause
- Simplified voice list

## Use Cases

**Audiobook Experience:**
- Listen while reading along
- Word highlighting keeps place
- Professional voice quality
- Adjustable speed for preference

**Language Learning:**
- Hear pronunciation while reading
- Slower speeds for comprehension
- Repeat difficult sentences
- See and hear simultaneously

**Accessibility:**
- Screen-free reading option
- Dyslexia support with highlighting
- Vision impairment assistance
- Multi-sensory engagement

**Productivity:**
- Listen during commute, exercise, chores
- Faster speeds for quick consumption
- Pause and resume seamlessly
- Continue across devices
