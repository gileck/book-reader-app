# 4.2 Full Reading Mode

## Purpose

Full Reading Mode provides a traditional e-reader experience where users can read multiple paragraphs continuously with smooth scrolling. It's designed for immersive reading sessions with optional audio narration and customizable visual settings.

## Design/Layout

**Reading Area:**
- Centered column with maximum width of 800px (optimal reading line length)
- Warm, sepia-toned background (Apple Books-inspired)
- Clean typography with generous line spacing
- Chapter title displayed at top in larger, uppercase text
- Paragraphs separated by consistent spacing
- Current sentence highlighted with warm yellow background

**Visual Hierarchy:**
- **Chapter Header**: Larger font, uppercase, accent color, centered
- **Paragraphs**: Standard reading font, left-aligned, comfortable spacing
- **Current Sentence**: Yellow highlight (semi-transparent) with rounded corners
- **Images**: Full-width, click to view fullscreen
- **Page Numbers**: Subtle footer showing progress through chapter

**Fullscreen Mode:**
- Removes tab navigation and all chrome
- Floating control panel at bottom center with:
  - Progress bar showing chapter completion
  - Previous/Next sentence buttons
  - Typography controls (font size, color)
  - Auto-scroll toggle with speed slider
  - Exit fullscreen button
- Controls auto-hide after 3 seconds of inactivity
- Mouse movement brings controls back

## User Interactions

**Reading:**
1. User scrolls naturally through chapter content
2. Current playing sentence (if audio active) highlighted in yellow
3. Auto-scroll feature keeps current sentence centered
4. Click "Jump to Current" button to scroll to playing sentence

**Navigation:**
1. **Scroll**: Use mouse wheel or touch swipe to move through content
2. **Click Sentence**: Click any sentence to navigate playback to that position
3. **Previous/Next Chapter**: Buttons in header to switch chapters
4. **Progress Bar**: Shows visual indicator of chapter progress

**Entering Fullscreen:**
1. User clicks fullscreen icon in audio controls
2. Screen transitions to fullscreen with fade animation
3. All UI chrome disappears
4. Floating control panel appears at bottom
5. Reading content expands to fill screen

**Auto-Scroll Feature:**
1. User toggles auto-scroll in fullscreen controls
2. Content begins scrolling automatically at set speed
3. Speed adjustable via slider (20-200 pixels/second, default: 60 px/s)
4. Pauses immediately when user manually interacts (scroll, touch, click)
5. Must manually re-enable auto-scroll (no automatic resume)

**Interacting with Sentences:**
1. **Single Click**: Navigate audio to clicked sentence
2. **Double Click**: Opens context menu with options:
   - "Translate this sentence"
   - "Ask question about this"
   - "Bookmark here"
3. **Right Click**: Same context menu (desktop)
4. **Long Press**: Context menu (mobile, 500ms delay)

**Customizing View:**
1. User opens customization panel (paintbrush icon)
2. Adjusts font size with slider
3. Changes text color from presets or custom picker
4. Modifies line height and spacing
5. Changes apply in real-time to reading area

## Special Features

**Bionic Reading:**
- When enabled, first part of each word appears in bold
- Helps eyes move faster through text
- Toggle on/off in customization settings
- Example: **Hel**lo **wor**ld, **th**is **i**s **a** **tes**t

**Paragraph Detection:**
- Automatic paragraph spacing
- Visual break indicators for scene changes
- Preserves original book formatting

**Image Handling:**
- Images appear full-width in reading flow
- Click image to view fullscreen
- Zoom and pan in fullscreen view
- Close fullscreen with X button or escape key

**Link Detection:**
- Footnote references shown as clickable superscript
- Click to jump to footnote definition
- Internal chapter links navigate within book
- External links disabled for distraction-free reading

## Visual States

**Normal Reading:**
- Clean background, readable text
- Current sentence: subtle yellow highlight
- Smooth scroll behavior

**Audio Active:**
- Current sentence: bright yellow highlight
- Word-level highlighting (optional, shows which word is speaking)
- Auto-scroll keeps current sentence in view

**Fullscreen:**
- Full screen immersion
- Minimal controls that auto-hide
- Larger text (110% of normal size)
- Progress indicator always visible

**Loading:**
- Skeleton text blocks while chapter loads
- Smooth fade-in when content ready

**Error:**
- "Content unavailable" message if chapter fails to load
- Retry button to reload
- Link to previous/next chapter

## Responsive Behavior

**Desktop (>1024px):**
- 800px max-width reading column
- Generous margins on sides
- All controls visible
- Hover states on interactive elements

**Tablet (768-1024px):**
- Slightly narrower reading column (600px)
- Reduced margins
- Touch-optimized controls

**Mobile (<768px):**
- Full-width reading area with padding
- Larger touch targets
- Bottom-anchored controls
- Simplified context menu

## Auto-Scroll - Technical Details

### Implementation

Auto-scroll uses `requestAnimationFrame` for smooth, performance-optimized scrolling with delta-time-based calculations.

### Speed Configuration

**Default:** 60 pixels/second
**Range:** 20-200 pixels/second
**Adjustment:** ±1 pixel/second increments via UI controls
**Setting Storage:** Saved in user settings (persists across sessions)

### Scrolling Algorithm

```
Algorithm (runs every frame):
1. Calculate time delta since last frame (in seconds)
2. Scroll amount = Speed (px/s) × Delta time (s)
3. Apply scroll: container.scrollTop += Scroll amount
4. Check if near bottom (within 4px threshold)
5. If near bottom: Stop auto-scroll automatically
6. Otherwise: Schedule next frame
```

**Frame Rate:** Targets 60fps via `requestAnimationFrame`
**Smoothness:** Delta-time ensures consistent speed regardless of frame rate

### Pause/Stop Behavior

**Triggers that stop auto-scroll:**
- Mouse wheel event
- Touch start event (mobile)
- Mouse down event (click/drag)
- Reaching bottom of content (auto-stop)

**No automatic resume:**
- User must click play button again to restart
- Prevents unexpected scrolling after user interaction

**Near-bottom detection:**
- Threshold: 4 pixels from bottom
- Formula: `scrollTop + clientHeight >= scrollHeight - 4`
- Prevents scrolling past content end

### Performance Optimizations

**Efficient Updates:**
- Uses `requestAnimationFrame` (browser-optimized)
- Delta-time calculation ensures smooth scrolling
- No DOM measurements per frame
- Pure arithmetic calculations only

**Event Listeners:**
- Passive listeners where possible (non-blocking)
- Properly cleaned up on component unmount
- No memory leaks

**Typical Performance:**
- CPU usage: <2% during auto-scroll
- Frame drops: None on modern devices
- Battery impact: Minimal

### Edge Cases

**Very Fast Speeds (>150 px/s):**
- Content may blur during rapid scrolling
- User warned if speed set too high
- Still maintains smooth 60fps

**Long Chapters:**
- No performance degradation
- Scroll position tracked accurately
- Stops precisely at content end

**Window Resize:**
- Auto-scroll continues smoothly
- No recalculation needed (speed is absolute)
