# 4.8 Audio Controls

## Purpose

The Audio Controls provide a comprehensive control bar for managing TTS playback, navigation, and access to related features. The bar remains fixed at the bottom of the screen for constant access during reading.

## Design/Layout

**Control Bar:**
- Fixed position at bottom of screen
- Semi-transparent background with backdrop blur
- Three sections: Left (navigation) | Center (playback) | Right (features)
- Auto-hides in fullscreen mode (reappears on mouse movement)
- Safe area padding for mobile devices (iPhone notch, home indicator)

**Left Section (Navigation):**
- Previous Chapter button (skip back icon)
- Previous Sentence button (back arrow)
- Chapter selector button (shows current chapter)

**Center Section (Playback):**
- Large circular Play/Pause button
- Progress bar showing chapter completion (0-100%)
- Time remaining estimate: "23 min remaining"
- Current position: "Sentence 45 of 234"

**Right Section (Features):**
- Next Sentence button (forward arrow)
- Next Chapter button (skip forward icon)
- Jump to Current button (target icon, appears in Full mode)
- Go to Top button (up arrow)
- Bookmark toggle (star icon, filled if bookmarked)
- Settings button (gear icon)
- Fullscreen toggle (expand icon)

**Progress Bar:**
- Thin bar spanning width of center section
- Filled portion in accent color (orange/amber)
- Empty portion in light gray
- Shows percentage text on hover: "45%"
- Clickable to jump to position (future feature)

## User Interactions

**Play/Pause:**
1. User clicks large play button
2. Audio begins playing current sentence
3. Button icon changes to pause
4. Word highlighting starts
5. User clicks pause
6. Audio stops immediately
7. Button returns to play icon
8. Highlighting stops on current word

**Next/Previous Sentence:**
1. User clicks next sentence button
2. Current audio stops
3. Advances to next sentence
4. Highlights new sentence
5. If playing, audio starts automatically
6. If paused, remains paused at new position

**Next/Previous Chapter:**
1. User clicks next chapter
2. Confirmation if mid-chapter: "Leave current chapter?"
3. User confirms
4. Reader loads next chapter
5. Position resets to Chapter start
6. Audio state preserved (playing/paused)

**Chapter Selector:**
1. User clicks chapter button (shows "Chapter 5")
2. Modal opens with chapter list
3. All 24 chapters shown with titles
4. Current chapter highlighted
5. User clicks "Chapter 12"
6. Modal closes
7. Reader navigates to Chapter 12 start

**Jump to Current:**
(Only in Full mode, when scrolled away from current position)
1. User scrolled down to read ahead
2. Audio still playing at earlier position
3. "Jump to Current" button appears
4. User clicks button
5. Page auto-scrolls to currently playing sentence
6. Smooth scroll animation (1 second)

**Go to Top:**
1. User clicks up arrow
2. Reader navigates to first sentence of chapter
3. Smooth scroll to top
4. Audio state preserved

**Bookmark Toggle:**
1. User at important passage
2. Clicks star icon (currently outline)
3. Star fills in with accent color
4. Toast notification: "Bookmark created"
5. Click again to remove bookmark
6. Star returns to outline
7. Toast: "Bookmark removed"

**Settings Access:**
1. User clicks gear icon
2. Customization panel slides in from right
3. Shows theme, typography, TTS settings
4. User makes changes
5. Changes apply in real-time
6. Close panel to return to reading

**Fullscreen Toggle:**
1. User clicks expand icon
2. Screen enters fullscreen mode
3. All UI chrome disappears
4. Control bar auto-hides after 3 seconds
5. Mouse movement shows controls
6. Click collapse icon to exit fullscreen

## Special Features

**Loading Indicators:**
- Spinner icon on current sentence when TTS loading
- Progress bar fills as chapter loads
- Disabled state on buttons during loading

**Error Notifications:**
- TTS error banner appears above controls
- Shows provider, error code, message
- Retry and Skip buttons available
- Dismissible with X button

**Keyboard Shortcuts:**
- Space: Play/Pause
- Left Arrow: Previous sentence
- Right Arrow: Next sentence
- F: Fullscreen toggle
- B: Bookmark toggle

**Smart Button Visibility:**
- "Jump to Current" only shows when scrolled away
- "Go to Top" only shows when not at top
- Chapter navigation disabled if only one chapter

## Visual States

**Default State:**
- All buttons enabled and clickable
- Play button ready
- Progress bar showing current position

**Playing State:**
- Play button becomes pause
- Current word highlighting active
- Progress bar slowly fills
- Time remaining updates

**Loading State:**
- Spinner on current position indicator
- Play button disabled briefly
- "Loading..." text

**Disabled States:**
- Previous chapter disabled if on first chapter
- Next chapter disabled if on last chapter
- Grayed out, cursor not-allowed

**Error State:**
- Error banner at top of controls
- Red icon and message
- Action buttons (Retry, Skip, Change Provider)

## Responsive Behavior

**Desktop:**
- Full control bar with all buttons
- Wider spacing between buttons
- Hover states visible
- Keyboard shortcuts active

**Tablet:**
- Slightly condensed spacing
- Touch-optimized button sizes
- All features available
- Bottom safe area respected

**Mobile:**
- Most compact layout
- Essential buttons prioritized
- Some buttons moved to overflow menu
- Large touch targets (min 44x44px)
- Bottom padding for home indicator (iOS)

## Use Cases

**Continuous Listening:**
- Play button starts narration
- Auto-advances through chapter
- Progress bar shows advancement
- Pause when needed

**Precise Navigation:**
- Jump to specific sentences
- Skip ahead or review
- Switch chapters easily
- Return to top quickly

**Bookmark Management:**
- Mark important passages while listening
- Visual confirmation of bookmarked positions
- Quick toggle on/off

**Distraction-Free Reading:**
- Fullscreen mode hides all UI
- Controls reappear when needed
- Minimal interruption to flow
